### 2. Что нового добавилось в уровне Medium (интеграция с БД)

В уровне Medium к вашему существующему GUI приложению были добавлены следующие компоненты и возможности:

1. НОВЫЙ МОДУЛЬ database.py
Был создан отдельный модуль для работы с базой данных SQLite:

```python
class Database:
    - __init__()        # Подключение к БД
    - create_table()    # Создание таблицы tasks
    - add_task()        # Добавление задачи в БД
    - get_all_tasks()   # Получение всех задач из БД
    - update_task_status() # Обновление статуса задачи
    - delete_task()     # Удаление задачи из БД
    - delete_all_tasks() # Удаление всех задач
    - get_statistics()  # Получение статистики
```

2. БАЗА ДАННЫХ SQLite
Новый файл: tasks.db (создаётся автоматически)

Структура таблицы:

```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    text TEXT NOT NULL,
    done INTEGER DEFAULT 0,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    completed_at TEXT
)
```
Что это даёт:

- Задачи сохраняются между запусками программы

- Данные не теряются после закрытия приложения

- Возможность анализировать историю задач

### 6. Сравнение уровней Rare и Medium

| Характеристика | Уровень Rare | Уровень Medium |
|----------------|--------------|----------------|
| **Хранение данных** | В оперативной памяти (список `self.tasks`) | В файле БД SQLite (`tasks.db`) |
| **Сохранение после закрытия** | ❌ Нет (задачи теряются) | ✅ Да (задачи сохраняются) |
| **Структура задачи** | `{"text": str, "done": bool}` | `{"id": int, "text": str, "done": bool, "created_at": str, "completed_at": str}` |
| **Статистика в главном окне** | ❌ Нет | ✅ Да (всего, выполнено, в работе) |
| **Отдельное окно статистики** | ❌ Нет | ✅ Да |
| **Прогресс-бар выполнения** | ❌ Нет | ✅ Да |
| **Автоматическое создание БД** | ❌ Нет | ✅ Да |
| **История создания задач** | ❌ Нет | ✅ Да (поле `created_at`) |
| **История выполнения** | ❌ Нет | ✅ Да (поле `completed_at`) |
| **Уникальный ID задачи** | ❌ Нет (используется индекс) | ✅ Да (автоинкремент) |
| **Подтверждение удаления всех задач** | ✅ Да | ✅ Да |
| **Количество файлов в проекте** | 1 файл (`todo_app.py`) | 3 файла + БД |

**Вывод:** Уровень Medium значительно расширяет функциональность приложения за счёт постоянного хранения данных, статистики и аналитики.
